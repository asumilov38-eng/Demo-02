# SOLE — каталог кроссовок

Адаптивный демонстрационный сайт на HTML, CSS и JavaScript.

## Возможности
- Каталог из 12 демонстрационных моделей.
- Поиск по названию и бренду.
- Фильтры по полу, размеру и назначению.
- Сортировка по цене и названию.
- Избранное и интерактивные карточки.
- Адаптация под смартфоны, планшеты и компьютеры.

## Запуск
Откройте `index.html` в браузере. Установка зависимостей не требуется.

## GitHub Pages
1. Откройте Settings → Pages в репозитории.
2. В Build and deployment выберите Deploy from a branch.
3. Выберите ветку `main` и папку `/ (root)`, затем Save.
4. После публикации GitHub покажет ссылку на сайт.

Это демо-витрина: товары, цены и фотографии демонстрационные. Оформление заказов и оплата не подключены.
