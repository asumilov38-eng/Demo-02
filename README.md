# YVL STORE — каталог кроссовок

Адаптивный демонстрационный каталог без регистрации, корзины и оформления заказа на сайте.

## Как работает заказ

Кнопка «Заказать на Avito» открывает поиск соответствующей модели на Avito. Чтобы направлять покупателя на конкретное объявление, найди объект товара в массиве `products` в `index.html` и укажи его прямую ссылку в поле `avitoUrl` вместо пустой строки:

```js
avitoUrl: "https://www.avito.ru/..."
```

Если `avitoUrl` оставить пустым, сайт автоматически откроет поиск модели на Avito.

## Запуск

Открой `index.html` в браузере. Для публикации на GitHub Pages загрузи `index.html` в корень репозитория и включи Pages для ветки `main`.

## Важно

Модели, цены и изображения в каталоге демонстрационные. Перед запуском замени их на реальные товары, цены, размеры и прямые ссылки на объявления Avito.
